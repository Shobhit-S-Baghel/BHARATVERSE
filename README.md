# 🇮🇳 BharatVerse

**Your Journey. Intelligently Protected.**  
*A smart tourism platform built for the Smart India Hackathon (SIH) 2026 under the Yatridost initiative.*

BharatVerse is an intelligent travel itinerary generator and digital safety platform designed to promote Indian heritage. It helps tourists discover the rich cultural tapestry of India while prioritizing their safety and budget through personalized, data-driven insights. 

## 🚀 Key Features

* **Intelligent Itinerary Generator:** Generates customized, day-by-day travel plans (up to 7 days) based on user budget, interests (Heritage, Culture, Food, Nature, Festival), and selected destinations.
* **Tourist Safety Digital Twin:** A real-time telemetry dashboard providing a holistic "Twin Score" out of 100. It evaluates live environmental data, infrastructure vectors (weather, terrain, crowds), and dynamically calculates safety suitability for different personas (e.g., Solo Travel, Family Sightseeing, Elderly Visitors).
* **Dynamic Budget Allocation:** A visual, horizontal budget breakdown that intelligently divides your total trip budget into distinct categories: Accommodation, Food & Dining, Activities & Entry, and Local Transport.
* **Explore India Hub:** Curated heritage insights and high-quality visuals for prime cultural hubs across Madhya Pradesh (Indore, Ujjain, Gwalior), Rajasthan (Jaipur, Udaipur, Jaisalmer), and Gujarat (Ahmedabad, Bhuj, Somnath).
* **Seamless UI/UX:** Features a fully responsive Indian-heritage-themed design, a 3D interactive logo, and a built-in Dark Mode toggle for accessibility.

## 🛠️ Tech Stack

This prototype is built to be lightweight, fast, and completely free of heavy dependencies. 
* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **Architecture:** Single-page application structure (`BHARATVERSE_final.html`) using DOM manipulation for seamless dashboard transitions.
* **Typography & Styling:** Custom CSS Grid/Flexbox layouts, Google Fonts (Merriweather, Inter), and native CSS variables for theme switching.
